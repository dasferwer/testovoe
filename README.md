# Тестовое задание — CityCar

## 1. Архитектура решения

Оркестратор принимает запрос, фиксирует период и запускает три агента:

- **Сбор данных:** сделки и задачи через amoCRM REST API v4 с OAuth 2.0; звонки и записи — через API провайдера телефонии.
- **Анализ звонков:** распознавание речи, разделение по спикерам, извлечение потребностей клиента, возражений и договорённостей. Выводы сопровождаются таймкодами.
- **Аналитика и отчёт:** объединение звонков со сделками, расчёт продаж, конверсии, просроченных задач и пропущенных контактов. Числа рассчитываются кодом, AI формулирует выводы.

Данные и результаты хранятся в PostgreSQL, аудио — в защищённом объектном хранилище. Руководитель получает отчёт с проблемами, рекомендациями и ссылками на источники. Для анализа изменений этапов нужны история событий или заранее сохранённые снимки CRM.

## 2. Автоматизация, участие человека и риски

Система сама собирает данные, расшифровывает звонки, считает показатели и готовит рекомендации. Человек проверяет спорные выводы и утверждает изменения в CRM, контакты с клиентами и кадровые решения.

Три основных риска:

- Неполные данные и ошибки привязки звонков к сделкам.
- Ошибки распознавания и недостоверные выводы AI: нужны подтверждения и выборочная проверка.
- Конфиденциальность записей: ограничение доступа, шифрование и согласованные сроки хранения.

## 3. Получение сделок с просроченными задачами

Пример получает сделки с просроченными незавершёнными задачами, обрабатывает страницы и исключает дубли. Поля и фильтры — по [документации amoCRM](https://www.amocrm.ru/developers/content/crm_platform/tasks-api).

Для запуска нужны Python, пакет `requests`, поддомен аккаунта в `AMO_SUBDOMAIN` и действующий OAuth access token в `AMO_ACCESS_TOKEN`.

```python
import os
import time
import requests

base = f"https://{os.environ['AMO_SUBDOMAIN']}.amocrm.ru"
session = requests.Session()
session.headers["Authorization"] = (
    f"Bearer {os.environ['AMO_ACCESS_TOKEN']}"
)
params = {
    "filter[entity_type]": "leads",
    "filter[is_completed]": 0,
    "limit": 250,
    "page": 1,
}
lead_ids, now = set(), int(time.time())
while True:
    time.sleep(0.15)
    response = session.get(
        f"{base}/api/v4/tasks", params=params, timeout=30
    )
    response.raise_for_status()
    if response.status_code == 204:
        break
    data = response.json()
    for task in data["_embedded"]["tasks"]:
        if task["complete_till"] < now:
            lead_ids.add(task["entity_id"])
    if not data.get("_links", {}).get("next"):
        break
    params["page"] += 1

for lead_id in sorted(lead_ids):
    time.sleep(0.15)
    response = session.get(
        f"{base}/api/v4/leads/{lead_id}", timeout=30
    )
    response.raise_for_status()
    print(response.json())
```

В рабочем сервисе добавлю обновление OAuth-токена и повторы при 429/5xx.

## 4. Реальный AI-проект

[EvidenceRAG](https://github.com/dasferwer/evidence-rag) — мой портфолио-проект для ответов по базе знаний с указанием источников. Реализованы загрузка документов, фоновая индексация, гибридный поиск, история запросов и разграничение доступа.

Стек: Python, FastAPI, PostgreSQL с pgvector, RabbitMQ, SQLAlchemy, Docker; предусмотрено подключение OpenAI-совместимой LLM.

Результат — сервис с цитатами и версиями документов, повторной обработкой после сбоев и интеграционными тестами. Локальный режим использует тестовый провайдер.

## 5. Самостоятельное обучение

За последние полгода углубил знания RAG, векторного поиска и надёжной фоновой обработки. Применил их в EvidenceRAG: объединил векторный и полнотекстовый поиск, реализовал доставку заданий через transactional outbox и защиту от повторной обработки.

## 6. Собственная инициатива

Мой пример — улучшение надёжности EvidenceRAG при редактировании документов во время индексации. Добавил версии документов и проверку перед сохранением результата: запоздавший воркер больше не может записать устаревший текст. Дополнительно реализовал повторную проверку источников после генерации ответа. Интеграционные тесты воспроизводят эти ситуации и проверяют защиту.
